## Overview

A sleek, interactive quote calculator built for a client on Upwork. The application walks potential customers through a series of questions about their project requirements and generates an accurate, detailed quote in real-time.

![Quote Calculator - Main View](/images/projects/quote-calculator-1.png)

## The Problem

The client was spending hours manually creating quotes for each customer inquiry. Each quote required understanding the project scope, calculating costs for different features, and formatting a professional proposal.

## The Solution

I built a step-by-step wizard interface that:

- **Guides users** through project requirements with an intuitive multi-step form
- **Calculates costs** in real-time based on selected features and complexity
- **Generates quotes** as downloadable PDF documents
- **Saves data** for the client to review and follow up

![Quote Calculator - Features](/images/projects/quote-calculator-2.png)

## Tech Stack

- **Next.js** — full-stack React framework
- **React** — interactive UI components
- **Vanilla CSS** — custom responsive styling
- **PDF Generation** — automated quote document creation

## Key Features

1. **Multi-step wizard** — intuitive flow that doesn't overwhelm users
2. **Real-time pricing** — costs update instantly as options change
3. **Responsive design** — works perfectly on mobile and desktop
4. **PDF export** — professional quote documents with client branding

![Quote Calculator - Results](/images/projects/quote-calculator-3.png)

## Results

- Reduced quote creation time from **45 minutes to 5 minutes**
- **Professional appearance** increased client conversion rate
