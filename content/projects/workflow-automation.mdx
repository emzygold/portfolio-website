## Overview

A visual drag-and-drop workflow automation platform that allows businesses to connect their tools and automate repetitive processes. Think Zapier, but customizable and self-hosted.

## The Problem

Small businesses juggle dozens of tools — CRMs, email platforms, payment processors, spreadsheets. Data gets siloed, manual copy-pasting creates errors, and teams waste hours on tasks that should be automatic.

## The Solution

I built a visual workflow builder where users can:

- **Drag & drop** to create automation flows between services
- **Connect 20+ integrations** — Gmail, Slack, Sheets, Stripe, etc.
- **Set triggers** — run on schedule, webhook, or manual trigger
- **Add logic** — conditions, filters, loops, and data transformations
- **Monitor** — real-time logs, error alerts, retry logic

## Tech Stack

- **Node.js** — backend runtime and automation engine
- **React** — visual flow builder UI
- **Redis** — job queue and caching
- **REST APIs** — integration with third-party services
- **Docker** — containerized deployment

## Key Features

1. **Visual flow builder** — drag-and-drop nodes and connections
2. **20+ integrations** — connect popular business tools
3. **Conditional logic** — if/else branching, filters, loops
4. **Error handling** — automatic retries, error notifications
5. **Scheduling** — cron-based or event-triggered execution
6. **Audit logs** — full history of every automation run

## Results

- Saved clients an average of **15 hours/week** on manual tasks
- **Zero data entry errors** after automation
- **5-minute setup** for common workflows (email → spreadsheet, form → CRM)
