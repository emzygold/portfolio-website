## Overview

My personal portfolio website — the one you're looking at right now! Built with Next.js 15, Framer Motion, and a bold Amber + Cyan design language. Features dynamic scroll animations, a blog powered by MDX, and responsive design across all devices.

## Design Philosophy

I wanted a site that immediately communicates confidence and technical skill. The **Bold & Vibrant** design uses a dark base with warm amber and cool cyan accents to create a memorable, high-energy experience.

## Tech Stack

- **Next.js 15** — App Router with server components for optimal SEO
- **Framer Motion** — scroll-triggered animations, page transitions, hover effects
- **MDX** — blog posts and project pages written in Markdown
- **Vanilla CSS** — custom design system with CSS custom properties
- **Vercel** — automated deployments from GitHub

## Key Features

1. **Dynamic animations** — scroll reveals, typing effects, parallax orbs, counter animations
2. **MDX content** — projects and blog managed through simple Markdown files
3. **Responsive design** — optimized for mobile, tablet, and desktop
4. **SEO optimized** — server-side rendering, meta tags, sitemap, structured data
5. **Contact form** — integrated with Formspree for email delivery

## What I Learned

Building this portfolio taught me a lot about design systems, animation performance, and content architecture. The MDX-based content management makes it easy to add new projects and blog posts with just a `git push`.
